Boneset: Domino Puzzle — Support

Questions, bugs, ideas, data requests — one address: bonesetpuzzle@gmail.com.

What helps in a bug report

  • Your device and system version (for example, iPhone 15, iOS 26.1).
  • Where it happened: level number, a challenge, or a generated board.
  • A screenshot if there is something to see.

Common questions

  • No account, no sign-in. Progress lives on the device. There is no password to reset and no account to recover.
  • Works offline. Levels, challenges and the generator need no connection. Only the leaderboard rank is fetched online.
  • Every board has exactly one solution. If a board seems stuck, the set matrix and red duplicates show where the reasoning went off: undo a few tiles or jump back to your checkpoint.
  • Your data. What the game collects and how to get it deleted is in the privacy policy: App Store version, Google Play version, browser version.

Play

The browser version is at dmitrii-belich.github.io/domino. The same game is built for iPhone and iPad (App Store) and for Android (Google Play).
